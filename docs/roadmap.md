# Roadmap

## Editorial workflow

- Improve side-by-side candidate comparison for admins.
- Add clearer explanations for filtering and scoring decisions.
- Expand schedule previews across multiple bot profiles.

## Media

- Continue improving compatibility detection before download.
- Add more operator visibility into conversion decisions.
- Evaluate additional gallery and hosted-media formats.

## Operations

- Refine trend summaries without collecting unnecessary user data.
- Improve backup validation and recovery reporting.
- Add broader integration coverage with mocked Telegram and Reddit responses.

The roadmap does not include removing operator authorization or bypassing source-platform rules.
